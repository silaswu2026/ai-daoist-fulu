# 卡在前三句（约 3–5s）· 二轮根因

## 已排除
- 源片 3–5s **没有**视频时间戳空洞；`show_frames` 连续、包体正常。
- ffmpeg `-xerror` 全片解码通过 → **不是**「源片播到一半没数据」。
- 仅修 moov / 仅改 yuvj / 仅改 all-intra **都不能**解释「能播几秒再卡」。

## 真正对齐症状的两点
1. **口播气口处 AAC 几乎空包**（`pkt_size=4`）成串出现在 ~2.26–2.56s、以及后续 gap——正好落在「前三句之后」。部分手机播放器遇到音轨近乎空帧会停住画面等待。
2. **全 I 帧静帧片码率过高**（phone 版曾 ~12Mbps）→ 缓冲在前几秒后耗尽，表现为卡死；桌面 ffmpeg 仍能硬解所以本地看不出来。

## 源头修法（本版 `EP0-r6-streamable.mp4`）
- 全程垫粉红噪声床，消灭气口空 AAC
- 视频加时变 grain，`no-fast-pskip`，保持 P 帧有码
- Baseline · yuv420p · tv/bt709 · g=30 · bf=0 · +faststart · 码率封顶 ~2.8Mbps
- 540×960 聊天试看
