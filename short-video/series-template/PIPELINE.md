# 系列符可复用流水线（同款 EP0 理论）

## 首帧定妆（每条必遵）
1. **毛笔字风第一帧**：大字钩子（抖音爆款毛笔字感）+ 轻符影在背后
2. **符在画面背后**（半透明金线符箓）
3. **侧旁 AI 解构元素**：Prompt / Token / API / 节点连线，不抢主字
4. 整体道家金线×深青黑底

## 单条四段（口播+黄条）
1. 请了哪个道家神
2. 用了什么提示词
3. 符号里用了哪些提示词
4. 最后做什么愿

## 片尾 CTA（全系列统一）
占位：「链接见主页 / 评论置顶」→ 待 Silas 正式落地页 URL 后批量替换为 AI 自动生成符页。

## 命名
`v{NN}-{主题拼音}_review_rN.mp4` → 放行后 `_release_rN.mp4`
主题例：qishiye / facai / pingan / baohu-fumu / ...

## 生成步骤
1. GenerateImage 首帧（毛笔字+背后符+侧解构）9:16
2. 轻动效 GenerateVideo ≤15s 可拆段
3. edge-tts 道门男声（观众节奏包：气口 ≤0.4s；片尾 CTA ≤1.5s；见 AUDIENCE_PACING.md）
4. ffmpeg 黄条 + 片尾 CTA
5. 交主控核；未放行不发

## 验收闸门（Silas / 主控 SSOT）
1. 封面/首帧一眼想点开（符/道×AI 同框冲击）
2. 钩子够狠
3. 看完热血沸腾或强烈想点链接才过；没感觉=不过+必改点
流程：生成交核 → 主控过规格 → 短视频观众(8110ba12)审 → 主控终放行发布
