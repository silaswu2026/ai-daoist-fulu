# AI 解构道家符

用 AI 解构道家符箓，把「请神 / 烧纸 / 师承」映射到「调模型 / 付 Token / 接 API」，用短视频钩子引流到祈福落地页，为个人愿望生成可保存、可打印的符（壁纸、手机壁纸、背壳、印封等）。

## 这是什么

- **短视频线**：EP0「神仙就是模型」定认知 → 「起 / 保佑」愿望符系列  
- **落地页**：说祈愿 → 生成八字 → AI 出符 → 导出多形态输出物  
- **气质**：道家风格视觉 + 沉稳调侃男声；纯技术类比，不贬信仰、不承诺超自然效果
